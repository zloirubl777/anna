# АННА — демосайт для GitHub Pages

## Быстрый запуск

В корень нового репозитория GitHub положите `index.html`, `styles.css`, `app.js` и всю папку `assets/` из этого архива. В GitHub: **Settings → Pages → Deploy from a branch → main / (root) → Save**. Сайт появится по ссылке GitHub Pages после публикации.

Для проверки на своём компьютере можно открыть `index.html` в браузере или запустить локальный сервер в папке проекта: `python -m http.server 8000`. Никаких сторонних библиотек и API-ключей не требуется. Шрифт Manrope грузится через Google Fonts; если доступа нет, сработает системный шрифт.

## Что уже работает

- Главная страница с анимированным портретом Анны и текстовым интерфейсом.
- Меню: О компании, Открыть счёт, Рекомендации, Контакты, Мой портфель.
- Открытие **демонстрационного** счёта по псевдониму и профилю риска.
- Виртуальное пополнение, покупка и продажа условных инструментов, история операций.
- Три учебные модельные стратегии; предложения можно применить к демосчёту после подтверждения.
- Простые команды текстового чата: «Открой счёт», «Пополнить», «Подбери портфель», «Купи ОФЗ на 10000», «Продай фонд акций», «Покажи портфель».
- Локальное сохранение в браузере (localStorage). В другом браузере/устройстве портфель будет отдельным.
- Лёгкая анимация аватара на базе подготовленных слоёв: моргание, дыхание, микродвижения и волосы.

## Строгие ограничения

Это **только демонстрационный прототип**, не настоящая инвестиционная компания, не брокер и не лицензированный финансовый сервис. Нет реальных денег, сделок, рыночных котировок, клиентской идентификации или персональных инвестиционных рекомендаций. Не вводите паспортные/платёжные данные, настоящие ФИО, API-ключи или пароли.

GitHub Pages размещает только статические файлы и не подходит для настоящих финансовых/конфиденциальных операций. Состояние счёта легко изменить через браузер и поэтому оно не может использоваться для реальных расчётов. Псевдоним и демопортфель сохраняются только локально.

## Позже: подключение реальной Анны через YandexGPT

Подключить можно к существующему серверу, но потребуется:

1. Разместить API на отдельном HTTPS-домене и настроить проверку доступа (аутентификация и лимиты запросов).
2. Настроить CORS для домена GitHub Pages.
3. Перенести обработку сообщений на сервер `/api/chat` и связать с операциями портфеля. Все серверные операции должны проверяться и храниться в защищённой БД.
4. Держать ключ Yandex AI Studio **только на сервере**. Не включать его в HTML, `app.js` или git-репозиторий.

Существующий сервер по HTTP-IP из браузерной страницы HTTPS не будет работать из-за смешанного содержимого; используйте HTTPS.
